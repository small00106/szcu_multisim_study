# SZCU Multisim 学习电路

Multisim 电路学习与实验文件，包含运算放大、三极管放大、RC / RLC 响应、滤波、稳压电源、定时控制及振荡电路。

## 使用方法

使用 NI Multisim 14.0 打开 `.ms14` 文件，查看原理图并按需要进行仿真。仓库包含实验过程中的搭建版本与安全副本。

## 文件说明

- 共 40 个电路文件：26 个普通文件、14 个安全副本。
- 文件名以电路名称为主；同类版本用序号或版本说明区分。
- `_安全副本.ms14` 为原 Multisim 自动保存的安全副本，统一扩展名后可单独打开。
- 电路文件只更改名称，内容保持原样。新旧名称及 SHA-256 校验值见 [rename-map.json](rename-map.json)。
